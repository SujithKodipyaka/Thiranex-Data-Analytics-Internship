## 🛠️ Project Showcase

### 1. Customer Segmentation & Behavioral Matrix (Assignment 02)
* **Objective:** Group customer cohorts based on age, income brackets, and spending drivers using machine learning.
* **Tech Stack:** Python, Scikit-Learn, K-Means Clustering, Seaborn.
* **Key Outcome:** Identified 3 distinct customer segments and mapped dedicated marketing strategies to maximize conversions.
* **[View Code & Reports](./Assignment-02-Customer-Segmentation/)**

### 2. Predictive Revenue Forecasting Model (Assignment 03)
* **Objective:** Build an analytical forecasting architecture to predict multi-month corporate revenue trends.
* **Tech Stack:** Python, Scikit-Learn (Linear Regression), NumPy, Matplotlib.
* **Key Outcome:** Evaluated historical timelines against model benchmarks (R-Squared of 55.4%) to calculate business growth velocity.
* **[View Code & Reports](./Assignment-03-Predictive-Forecasting/)**

### 3. Data Cleaning & Reporting Automation Pipeline (Assignment 04)
* **Objective:** Engineer an automated ETL (Extract, Transform, Load) data script to eliminate manual data-entry errors and construct dynamic dashboards.
* **Tech Stack:** Python, Pandas DataFrames, Data Cleansing Automation.
* **Key Outcome:** Successfully automated the elimination of duplicate data, text formatting variations, and null value imputation, reducing reporting downtime to zero.
* **[View Code & Reports](./Assignment-04-Reporting-Automation/)**
